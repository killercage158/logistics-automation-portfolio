# Post draft rules

Write one social media post from the source text.

- headline: at most 60 characters, no question marks, no emoji.
- caption: 3 to 6 short sentences in the brand voice. Start with what changed. End with one
  practical step for the reader.
- image_prompt: one sentence describing a background photo for the card (no text in the image).
- Use only facts from the source text. If the source does not give a date or a number, do not add one.

Answer with JSON only, in this exact shape:
{"headline": "...", "caption": "...", "image_prompt": "..."}
